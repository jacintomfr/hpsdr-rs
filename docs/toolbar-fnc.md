# Toolbar layers and FNC's

The bottom toolbar has 8 boxes: 7 assignable function boxes plus the layer box `FNC(n)`.

* **8 layers**, FNC(0)..FNC(7). Tap `FNC(n)` for the next layer (7 wraps to 0); long press, or the function `FNC-`, for the previous one. Configs saved with 9 layers keep layers 0..7; the old ninth layer is dropped, and a saved current layer of 8 or more starts at 0.
* **FNC's** (MIDI action "FNC's", also assignable to any toolbar box): quick jump to any layer. It is not assigned by default; assign it in Settings -> Toolbar (long press a box) or in the MIDI settings (Key binding).
* While the list is open, a compact window above the toolbar shows one row per layer, `FNC(n)` followed by the 7 button labels of that layer (`-` for empty), the current layer highlighted. The bottom toolbar boxes show FNC(0)..FNC(7), the current layer lit. Pressing box k (tap, or the MIDI ToolBar k press) selects layer k, closes the list and returns the toolbar to normal. Tapping a row does the same.
* CLOSE, Escape, pressing FNC's again, opening the Menu or any full-screen window closes the list without changing the layer.
