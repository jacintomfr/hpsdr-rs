# Toolbar layers and FNC's

The bottom toolbar has 8 boxes, and every one of them is assignable: each of the 8 layers (0..7) holds 8 functions.

* **8 layers**, FNC(0)..FNC(7). The layer step is an ordinary function, **FNC** (MIDI action `ToolbarFuncNext`, list name "FNC (next layer)"). Wherever it is assigned, its box shows `FNC(n)` with the current layer; tap = next layer (7 wraps to 0), long press = previous layer. `FNC-` (previous) and `FNC's` (list) are assignable too. Configs saved with 9 layers keep layers 0..7; the old ninth layer is dropped, and a saved current layer of 8 or more starts at 0.
* **Default / migration:** the factory layout puts FNC in the 8th box of every layer. A saved layer row with 7 entries (the old layout, where the 8th box was a fixed FNC button) loads its 7 functions and gets FNC as its 8th entry, so nothing changes until you reassign it; a row with 8 entries loads as saved. Saving always writes 8 entries per row. Because a long press on an FNC box means "previous layer", reassign such a box in Settings -> Toolbar (not by long press).
* **Three-step workflow:** press the box with `FNC's` -> pick the layer in the list -> press the function. With FNC's you no longer need the FNC box; replace it with any function.
* **FNC's** (MIDI action "FNC's", assignable to any toolbar box): quick jump to any layer. Assign it in Settings -> Toolbar (or long press a box) or in the MIDI settings (Key binding).
* While the list is open, a compact window above the toolbar shows one row per layer, `FNC(n)` followed by the 8 box labels of that layer (`-` for empty), the current layer highlighted. The bottom toolbar boxes show FNC(0)..FNC(7), the current layer lit. Pressing box k (tap, or the MIDI ToolBar k press) selects layer k, closes the list and returns the toolbar to normal. Tapping a row does the same. Window budget: 78 px layer column + 8 x 108 px cells = 942 px of rows, ~958 px with the frame (limit 1024 - 2 x 24 = 976); height 46 + 8 x 30 + 8 x 10 = ~370 px, anchored 72 px above the bottom edge.
* CLOSE, Escape, pressing FNC's again, opening the Menu or any full-screen window closes the list without changing the layer.
* MIDI `ToolBar1`..`ToolBar8` ("Function" is ToolBar8) all press the box of that number and run what the current layer has there; there is no special case for box 8.
